Profile


Janorovic Volkov (pen name of Radit Jibril Irawan) is an Indonesian software developer, writer, and Wikimedia contributor. He has been contributing to the Indonesian Wikipedia since 2021 and became a Wikipedia administrator in 2025. He is also a Wikimedia Indonesia member and an interface administrator, with a particular interest in developing tools, gadgets, bots, and other technical infrastructure for Wikimedia projects. His interests include programming, psychology, politics, philosophy, and Central European history and culture, particularly topics related to the Czechia and Slovakia. Rather than focusing solely on content creation, he is especially interested in the technical and organizational infrastructure behind collaborative knowledge projects.

Software Projects


Outside Wikimedia Projects, Janorovic develops Liska Linux, an independently developed Linux distribution built around the philosophy:

“Precision over chaos. Isolation over compromise.”

Liska Linux emphasizes user control, minimalism, and explicit system management, combining an Arch-like approach to installation and system configuration with a package-management philosophy inspired by Gentoo. The distribution uses its own package manager, LKPM (Liska Package Manager), written in Rust, which intentionally avoids automatically installing dependencies by default and instead gives users explicit control over dependency installation. The Liska Linux ecosystem also includes several custom system utilities, such as LKFS for filesystem formatting and swap management, LiskaISO for creating installation media, and LkSystem, a Rust-based Linux init and service supervision system being developed as an alternative to conventional init or service-management solutions. Janorovic also develops reusable Rust libraries and utilities intended to provide a common foundation across the Liska Linux ecosystem.

Another of his projects is Black Fox, a small recovery-oriented operating system designed to repair, inspect, and recover other operating systems. Black Fox combines a minimal Linux kernel and BusyBox-based recovery environment with a lightweight Rust-based init system. Its toolkit includes filesystem and partition-management utilities, disk and image-recovery tools, filesystem-specific utilities, disk-health monitoring, RAID tools, file synchronization and recovery utilities, as well as additional maintenance and diagnostic tools. It also incorporates an EFI Shell environment, memory-testing capabilities, and QEMU-based testing workflows.

Through projects such as Liska Linux and Black Fox, Janorovic explores operating-system development, system recovery, low-level Linux tooling, package management, and software infrastructure. His work across Wikimedia and independent software projects reflects a broader interest in building reliable technical systems, whether for collaborative knowledge, operating systems, or developer tools.
